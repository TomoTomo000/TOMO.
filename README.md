# TOMO.

フロントエンドエンジニア・デザイナー TOMO のポートフォリオ兼ブログです。

## 構成

- TanStack Start / React / Vite
- Tailwind CSS
- microCMS（記事・タグ・画像）
- Cloudflare Workers（Webアプリの配信）

## コマンド

```powershell
bun run dev
bun run lint
bun run typecheck
bun run test
bun run build
bun run preview
bun run cf-typegen
```

検証後のデプロイは `bun run deploy` で行います。
